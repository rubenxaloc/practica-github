# practica-github
Este es el archivo READ.me, está en la mayoría de repos de GitHub y lo considero muy útil ya que, si no estoy equivocado, su función principal es dar contexto sobre el proyecto (el nombre del archivo traducido al castellano es léeme.md). 
Suele ser muy útil para anotar observaciones, por ejemplo la linea x a veces falla o renombrar la variable xxxx.
Además es muy cómodo por si el creador del proyecto aparta este repo durante un tiempo, lo común sería que el programador se olvide del funcionamiento del código, las variables, etc, pero leyendo el documento puede recordar la información importante.
No es solo útil para un proyecto de un solo creador, si el repo es trabajado por  un equipo, el otro compañero puede ver qué cambios ha implementado el compañero para tenerlos en cuenta en el código y no pasarlos por alto.
